<objective>
Two opposing alt-text directions, both required by REQ A11Y-01 / A11Y-02:

1. **Decorative-hero inversion:** Six (or more) full-bleed background hero img tags currently carry descriptive alt text like `alt="Cornish Coastline"`. These are decorative — the headline carries the meaning. INVERT each to `alt=""` with `role="presentation"` so screen readers skip them.

INVERT each to `alt="{{ with $.Params.imageAlt }}{{ . }}{{ end }}"` — emits descriptive alt when authors set `imageAlt:` in front matter, falls back to empty alt (decorative) when missing. **Never** falls back to the title.

3. **Backfill** the `imageAlt:` field on the 8 existing posts (3 news + 5 press). Update the archetype so future posts prompt authors.

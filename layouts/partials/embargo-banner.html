on every page of a preview build (HUGO_ENVIRONMENT=preview). Reads the section's preview_lift / title from the nearest ancestor with a `preview_lift` param (Hugo walks .Parent up the section tree). Falls back to safe defaults if missing. Inline-in-content rather than position:fixed on purpose — so screenshots and copy-paste from journalists carry the banner with them. */}} {{- $section := . -}} {{- /* Walk up until we find a section that declares preview_lift. */ -}} {{- range $i, $_ := seq 6 -}} {{- if and $section (not $section.Params.preview_lift) -}} {{- $section = $section.Parent -}} {{- end -}} {{- end -}} {{- $lift := "" -}} {{- $sectionTitle := "" -}} {{- with $section -}} {{- $lift = .Params.preview_lift -}} {{- $sectionTitle = .Title -}} {{- end -}} {{- $liftLabel := "" -}} {{- with $lift -}} {{- $t := time.AsTime . "Europe/London" -}} {{- $liftLabel = $t.Format "Monday 2 January 2006, 15:04 MST" -}} {{- end -}}
